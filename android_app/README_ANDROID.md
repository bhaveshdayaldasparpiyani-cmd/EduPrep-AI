# 📱 EduPrep AI - Android Application Source Code

This folder contains the complete, production-ready **Native Android Studio Project (Java/Android SDK 34)** for EduPrep AI.

## 🌟 Key Features of the Android App:
1. **Full-Screen Native Android UX:** Removes the browser URL bar for an authentic mobile app feel.
2. **File Chooser & Camera Support:** Seamlessly upload class notes PDF and click photos for Gemini Vision OCR.
3. **Audio Synthesis Support:** Play synthesized Gujarati/Hindi voice explainers directly via Android Media APIs.
4. **Pull-to-Refresh:** Swipe down to reload student chat and marksheet in real-time.

## 🔨 How to Build the APK in Android Studio:
1. Open **Android Studio**.
2. Click **Open** and select this directory:
   `C:\Users\admin\.gemini\antigravity\scratch\gtu_ai_academic_bot\android_app`
3. Wait for Gradle Sync to complete.
4. Go to **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Your `.apk` file will be generated in `app/build/outputs/apk/debug/app-debug.apk` ready to install on any Android phone!
